# linkedin-post

Images for Kuldeep Jangir's daily LinkedIn posts.

Each image is generated by the daily scheduled Claude task and stored at
`images/YYYY-MM/YYYY-MM-DD-<format>.png` (1080x1080 PNG). Buffer reads the
image from its public raw URL, so files here must stay in place while a post
is still a draft or scheduled:

`https://raw.githubusercontent.com/jspeedluk/linkedin-post/main/images/YYYY-MM/<file>.png`

## Making an image

1. Write a 1080x1080 HTML page (see `examples/this-or-that.html` for the house style:
   light background `#F6F8FC`, deep blue `#0B3D91`, dark navy text `#0B1F4B`, Inter,
   flat shapes, no people, no logos, at most 12 words on the image).
2. Render it: `NODE_PATH=$(npm root -g) node tools/render.js /abs/path/page.html /abs/path/out.png`
3. Look at the PNG before using it.
